# Anime Art Portfolio

A free, responsive static portfolio for original anime-inspired illustrations and dark-fantasy concepts.

## Website URL
After GitHub Pages is enabled, the site should be available at:

https://oreki123hehe.github.io/anime-art-portfolio/

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for deployment to finish, then open the website URL above.

## Before submitting as a contributor portfolio
The artwork panels currently contain simple inline SVG decorative placeholders, not finished anime illustrations. Replace them with your own original, high-quality artwork before presenting the site as a professional contributor portfolio. Do not upload characters copied from existing anime, work made by someone else without permission, or content whose rights you do not hold. If artwork is AI-generated, follow the target platform's current disclosure, quality, and licensing requirements.

No paid hosting, external JavaScript libraries, or build tools are required.
